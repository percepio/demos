# Run the demo on STM32U585 hardware

This optional target supports the **ST B-U585I-IOT02A / STM32U585** board.
Complete the [host setup](../README.md) for CMake, Ninja, the Arm toolchain and
VS Code. QEMU is only needed for the emulated target.

## Install and configure OpenOCD

Use ST's OpenOCD distribution, such as the one bundled with STM32CubeIDE. It
must include `interface/stlink-dap.cfg` and `target/stm32u5x.cfg`.

Open [`.vscode/settings.json`](../.vscode/settings.json) and set the paths for
your installation:

```json
{
  "demo.openOcdPath": "/absolute/path/to/openocd",
  "demo.openOcdScripts": "/absolute/path/to/st_scripts"
}
```

On Windows, use the path to `openocd.exe` and forward slashes in JSON. The script
directory must contain `interface/` and `target/`. Linux also requires the probe
vendor's udev rules and USB permissions.

## Build and debug

The board must have TrustZone disabled and use a single-image configuration.

1. Connect the board's ST-LINK USB port to your computer.
2. Select **STM32U585: ST-LINK (OpenOCD)** in VS Code's Run and Debug dropdown.
3. Press **F5** to build, program the board and stop at `main`.
4. Press **F5** again to run, or **Shift+F5** to end debugging.

For a full rebuild, press **Ctrl+Shift+B** and choose **STM32U585: clean build**.
Firmware files are generated in `build/stm32u585-debug/`.

For a command-line build without connecting a board:

```text
cmake --preset stm32u585-debug
cmake --build --preset stm32u585-debug
```

## View output and alerts

Open the ST-LINK virtual COM port in a serial terminal at **460800 baud** to
view USART1 output. Save the serial output to a file to use it with the Detect
receiver. Follow the [Detect steps](../README.md#5-view-alerts-in-percepio-detect)
using `build/stm32u585-debug/Demo-FreeRTOS-QEMU.elf` and the captured serial log.

## If ST-LINK cannot be opened

Close other debugger sessions and tools using ST-LINK, including older OpenOCD
processes. Reconnect the board and check its USB driver and permissions if the
problem persists. `spawn openocd ENOENT` means the executable path needs to be
corrected in `.vscode/settings.json`.
